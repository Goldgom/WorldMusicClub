              How to read this check · 如何理解结果

              A group contains physical targets at exactly the same expected score time. Every target must match within the timing window for the group to be complete. A partial chord stays incomplete. The longest sequence follows expected score order; extra inputs affect accuracy separately and do not break this coverage count. 每组包含乐谱中同一预期时刻的实际起音目标，全部命中才算完整；和弦漏音则该组不完整。最长连续组按乐谱顺序统计，多余起音另计入准确率，不打断此覆盖计数。

              This is an onset coverage summary, not a combo or an error-free streak. Complete groups do not prove simultaneous chord attacks or perfect timing. Sustain, release and pedal are not scored. Very late input timestamps can revise this check. 这是起音覆盖统计，不代表无误连击、和弦同时弹下或节奏完全准确；延音、松键和踏板不评分，迟到的输入时间戳可能更新结果。
