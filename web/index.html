        Practice settings · 练习设置

        Written beats start at 0; B is exclusive. Use numbers or fractions (for example 3/2). Tempo and score changes clear the loop. Repeat-expanded scores need an explicit pass selector and cannot loop yet.

        Positive values subtract delay from recorded note-on timing; negative values add it. Range −500 to +500 ms. Changing this setting resets the current take. This is a manual correction, not automatic device calibration.
