# Curated score assets

Application code is MIT; these score assets carry their own edition license. The first complete source edition is Schubert's *Wandrers Nachtlied*, D.768, using the CC0 OpenScore Lieder edition. Each directory contains its exact CC0 text and provenance, plus a canonical score whose retained source envelope holds the complete original MSCX, raw converted MusicXML, explicitly normalized import copy and reference MIDI bytes with hashes.

This is written-note practice. Full source retention and exact converted MusicXML note/rest preservation do not imply that ornament, fermata, dynamic, lyric, layout or instrument-controller semantics are all rendered or performed. Read the visible warnings and `docs/CATALOG_RIGHTS.md`. No converter executable, SoundFont, commercial audio, scan or modern translation is bundled.

The fixed `sources/` candidate ledger records evaluation inputs and held works, not automatic admission. `index.json` lists explicitly included practice editions. None of the held Brahms, Schubert D547 or Clara Schumann candidates is silently added here.
