# WorldMusicHub 首次使用

这是早期测试版：Rust 负责乐谱、时间与评分，界面在本机浏览器中打开。程序只监听 `127.0.0.1`，无需注册账号；乐谱不会上传到云端识谱服务。

## Windows 启动

1. 完整解压 Windows ZIP，双击 `WorldMusicHub.exe`，保留控制台窗口
2. 浏览器会打开本机练习室；关闭控制台即可停止服务
3. 默认端口为 7878。端口被占用时可用 `WorldMusicHub.exe --port 7879`，但不同端口的浏览器曲库彼此独立
4. 如不希望自动打开浏览器，使用 `--no-open`，再打开程序打印的本机地址
5. 用 `WorldMusicHub.exe --version` 可直接查看版本，不会启动服务器；`--help` 查看启动选项。未知选项和错误端口会明确退出
6. 初版未签名。如果系统或浏览器显示安全警告，请核对官方仓库、构建记录和校验和，不要盲目绕过警告

## 第一遍练习

- 先选内置原创练习，设置钢琴键数与最低音，使用 Listen 听一遍
- 切换 Practice 前，等待乐器兼容性检查通过；超出音域或存在已知吉他弦冲突时，评分会被阻止
- 可用界面按键、映射的电脑键盘，或主动连接支持的 MIDI 设备。实际 MIDI 硬件与声卡延迟需要在你的电脑上测试
- 评分目前主要判断按下时的音高和时间，不判断踏板、松键、指法或演奏表现力
- 每次评分后可展开按音高统计，查看各键的目标、命中、漏按、多按，以及已命中音符的时间偏差。漏按和多按分别记录，软件不会猜测你原本想弹哪个音；少量样本和设备延迟都可能影响时间统计
- 同时同音的钢琴声部会共用一个物理击键目标，但原谱、声音时间线和来源映射均保留
- 校准正延迟值会从输入时间中减去该值。循环边缘存在归属歧义时，请查看提示和导出的演奏记录，不要把临时评分当成确定结论

## 导入与转换

- 支持本项目 JSON、受支持的 MusicXML/MXL、有限的 MIDI，以及项目自定义的 `.jianpu` 文本格式
- 新导入的 MXL 会把完整压缩包和选中的原始 XML 一并归档；可在来源文件中分别下载，JSON/曲库备份也会保留它们。完整归档超出 8 MiB 保存上限时会明确拒绝。旧版已导入记录可能只有 XML，需重新导入原 MXL 才能补齐
- 导入 PNG/JPEG 乐谱片段后，先裁剪一条清晰、水平的高音谱表，再检查识别建议
- 图片识别不会自动保证节奏、升降号、调号、和弦、声部、延音线等正确。每个音高和时值都需要人工核对；显示的百分比只是形状启发式分数，不是识别准确率
- 检查后的单旋律片段可显示简谱；能完整表达时，也可以预览并下载可编辑的简谱文本
- 多声部、和弦、反复、延音线、弱起等复杂结构请保留 JSON/MusicXML。文本导出遇到不能表达的情况会报错，不会偷偷删掉音符
- 受支持乐谱默认显示离线专业五线谱，也可切换简化音高导引或简谱。可主动开启小节跟随；手动翻页会暂停跟随，不会改动播放时间。它仍不能代替完整制谱编辑器；原始导入源会保留在标准乐谱中

## 完整曲目与原稿

内置舒伯特《Wandrers Nachtlied, D.768》的 CC0 版本包含完整 14 小节、324 个有音高的记谱片段和 10 个休止符。延音线连接后形成 321 个播放事件。这里提供按书面音符练习的版本：回音装饰、延长记号、力度、歌词等仍留在原稿中，并非都会在播放或生成的五线谱中重现。请打开“来源与限制”查看说明。

这首曲子的钢琴最低音低于默认 61 键范围。可以单独选人声声部，改用合适的键数/最低音，或明确确认可还原的八度改编；软件不会为了能评分而悄悄删音。显示后半页或只练一个声部，也不会裁掉保存的完整乐谱。

保存 JSON 或导出曲库备份才能保留整套原稿、许可、转换记录和警告。只导出 MusicXML/简谱，不等于完整归档。原始谱面可能包含个人信息或有版权的内容，分享前应自行核对。

乐谱 JSON 通常带缩进，方便阅读。如果只有缩进会让文件超过 8 MiB 导入上限，下载会改用紧凑 JSON 并提示，音符、元数据和来源内容保持相同。如果已载入的旧记录或补齐字段后的对象本身仍超限，仍可保留完整紧凑副本，但会明确提示当前版本不能重新导入；请同时保留原始输入。

## 保存与版权

点击 Save 才会保存到当前浏览器曲库。换浏览器、浏览器用户、端口或无痕窗口会看到不同的曲库；清理浏览器数据也可能清除保存内容。请另外导出乐谱或曲库备份。备份中可能包含原始乐谱图片和文件，分享前请确认愿意公开这些内容且有相应权利。
