## Included interface changes

- Search and filter the bundled song lobby, then prepare a candidate without replacing a paused take. Selected title, composer, opening musical metadata and Start controls stay visible while detailed notices scroll.
- Listen and Practice explicitly activate the selected score and start playback or count-in. Range and compatibility checks remain visible and can prevent Practice from starting.
- The piano stage gives falling notes and the complete configured keyboard the main area. Settings, import, retained sources, results and saved scores use secondary panels. Returning to Songs or opening a panel pauses playback; Resume returns to that paused session.
- The optional score dock retains professional staff engraving, the named simplified pitch guide and jianpu. Short landscape windows preserve visible notation by placing optional display choices in Help.
- Captured inputs and checked onset match rates are distinguished. Delayed input and stale revisions hide old rates; a 100% onset match rate is not a claim of perfect timing or expressive performance.

The later expanded Results summary and guitar upcoming-pitch strip are not part of commit 119. Guitar in this package still highlights current pitch options; it does not provide the newer advance timing strip or validated fingering.

## Remaining boundaries

This is an unsigned portable Rust application with a browser-rendered interface. Physical MIDI devices, speaker/input latency and assistive-technology use have not been verified. Assessment covers note-on pitch and timing, not sustain, release, pedal, fingering or full musical expression. Image recognition remains limited and requires manual review; the optional external OMR review bridge is not a bundled general recognizer. Imported originals and limitations remain available in Score. Independent security verification is incomplete.

Commercial rhythm-game requests remain metadata and official-source links unless a redistribution license is verified. The included original exercises, public-domain excerpts and CC0 D768 edition retain their separate source and rights records.
