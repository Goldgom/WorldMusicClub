# Recovery candidate for the first alpha milestone

The native Windows build at commit 50 completed successfully, including real Rust-backed browser and offline-engraving tests, full API smoke, ZIP inventory and extracted-executable checks. Its separate Verify workflow had one mocked-browser failure: the test's fake animation clock intercepted Playwright's own polling callbacks. The original failure remains recorded; it is not retrospectively called a pass.

The recovery candidate uses the corrected clock harness and later source fixes:

- Saved-library previews/Save snapshot guards follow score replacement while the dialog is open
- Numbered-text import accepts one leading UTF-8 BOM while retaining the exact original source; internal/repeated markers still fail clearly
- Test-only clock freezing now isolates the app animation callback and preserves normal browser/test polling
- An explicitly requested, bounded recovery gate produces a separately named Windows package with its actual source SHA/count and `recovery_for: 50`

This recovery package is not binary-equivalent to the commit-50 package. Both artifacts remain distinguishable by source SHA, filename, inventory and checksum. It is only accepted after the corrected complete Verify workflow and native Windows recovery packaging both pass. Read the original alpha's feature/rights/hardware/security limits; they still apply.
