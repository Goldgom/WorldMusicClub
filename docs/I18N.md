# Display-locale foundation

This is an incremental foundation, **not a claim that the whole interface is
localized**. Existing English/bilingual controls are unchanged until their owners
explicitly integrate this service. Adding keys alone does not convert a surface.

## Contract

`web/i18n.js` has no external dependencies and no import-time browser side effects.
The bundled, immutable `web/locales/zh-CN.js` and `web/locales/en.js` catalogs have
the same explicit `MESSAGE_SCHEMA`. Initial coverage is focused on free-recording
labels, computer-keyboard help/settings and error codes, navigation/settings,
stage text/ARIA, numbered-notation labels, and guitar/follow essentials.

- The default is `zh-CN`; `en` is the other supported choice. Browser language is
  not used to override this default. `zh-TW`, `zh`, and `en-US` are not accepted
  aliases or claims of additional locale support.
- `createI18n({storage, setDocumentLanguage, onReport, locale})` creates independent
  display state. All options are optional. A valid explicit `locale` overrides a
  valid saved choice; omit it to use the default-or-saved behavior.
- `storage` defaults to `null` (memory only). Pass a Storage adapter or a function
  returning one. The function form also catches exceptions raised by accessing
  `window.localStorage` itself. Only exact, bounded `zh-CN`/`en` strings are read
  and written under `worldmusichub.locale.v1`; arbitrary JSON is never parsed.
- `setLocale(locale)` returns true for accepted choices, including an unchanged
  explicit choice. An unchanged choice retries persistence without a redraw.
  Invalid choices return false and leave display/persistence unchanged. Failed
  reads/writes are reported; switching still works for this tab.
- `createDocumentLanguageAdapter(document)` supplies a setter that changes only
  `document.documentElement.lang`. DOM mutation is opt-in through this adapter.
- `locale` and monotonically increasing `revision` are readable properties.
  `subscribe(listener)` emits `{type, locale, previousLocale, revision}` when a
  locale changes or `invalidate()` explicitly requests a redraw. It does not fire
  on subscription. The returned unsubscribe is idempotent. A failing observer
  cannot prevent other observers from updating.
- `t(key, params)` accepts named, own data parameters with explicit schema types:
  text strings up to 8,192 UTF-16 code units, safe integers, or nonnegative safe
  integer counts. Missing, unexpected, inherited, getter-backed, or wrong-type
  parameters return a localized neutral fallback and generate a structured report.
  Text is not coerced from objects. Source strings remain unchanged within this
  display bound; overlong values are rejected, never silently truncated in data.
- Plurals are explicit catalog branches selected with `Intl.PluralRules`,
  including signed semitone offsets. Numeric parameters use `Intl.NumberFormat`.
  Translation keys and complete sentences replace English suffix construction.
- `formatNumber(number, options)` formats finite numbers; `formatDateTime(value,
  options)` accepts a Date, epoch-millisecond number, or UTC ISO timestamp with
  seconds and optional 1–3 fractional digits. Date formatting defaults to the
  browser timezone; an explicit Intl `timeZone` can be supplied. Display locale
  is not a timezone. These functions do not rewrite export values.
- `formatDuration(milliseconds, {fractionDigits: 0..3})` is elapsed `m:ss`, with
  minutes allowed above 59. It floors subsecond values and never uses a Date or
  timezone. Negative, nonfinite, or larger-than-safe-integer durations are rejected.
- `message(stableCode, params)` maps only known `ERROR_MESSAGE_KEYS` to `t()`.
  It does not accept or parse an exception's English `message`, translate
  arbitrary engine prose, or mutate the original exception. The twelve
  `keyboard_*` configuration error codes have specific explanations. Other
  defined code entries are integration contracts, not automatic controller
  adapters. New controller codes need explicit mappings when integrated.

Unknown keys/codes never fall back to another language's source text. A selected-
language neutral message is returned. The default reporter logs structured
issues to the console; callers may replace `onReport`. `getReports()` returns a
copy of the most recent 64 distinct reports, without parameter values or stored
contents. Repeated retained issues are deduplicated. Reports and rendering are
separate: e.g. show `error.preferenceStorage` when a persistence report warrants
a user notice. Do not turn diagnostic reports into recording-state changes.

## Minimal integration

```js
import {createI18n, createDocumentLanguageAdapter} from './i18n.js';

const i18n = createI18n({
  storage: () => window.localStorage,
  setDocumentLanguage: createDocumentLanguageAdapter(document),
});

function redrawDisplayText() {
  stopButton.textContent = i18n.t('free.stop');
  keyboard.setAttribute('aria-label', i18n.t('keyboard.title'));
  languageSelect.value = i18n.locale;
  // Update open dialogs, Canvas text and accessible labels here too.
  // Include i18n.revision in every memoized display signature.
}
redrawDisplayText();
const unsubscribe = i18n.subscribe(redrawDisplayText);
languageSelect.addEventListener('change', () => i18n.setLocale(languageSelect.value));
```

The selector's values remain stable `zh-CN`/`en`, while its label/option display
comes from `settings.language`, `settings.chinese` and `settings.english`.

`t()` returns **plain text**, not trusted HTML. Assign to `textContent`, a text
node, Canvas `fillText`, or a safe text attribute such as `aria-label`/`title`.
It intentionally does not HTML-escape a user title: text APIs display that title
literally. Never pass translation output to `innerHTML`, a URL, event handler, or
CSS sink. Existing string-built SVG renderers must XML-escape the returned text
exactly once, including interpolated source values, at the string-render boundary.
For links/emphasis create explicit, controlled DOM nodes, not markup templates.

Locale switches must preserve controls/focus, open dialog drafts, recordings,
input ownership, transport state, original titles/lyrics/provenance, source part
IDs, XML, diagnostics codes and canonical rational times. A redraw must not
compile/reload a score, restart a take, or stop/restart input.

## Remaining application work and verification

This module does not translate or subscribe existing surfaces by itself. Full
integration still needs the selector and every menu/help/status/error/results
surface; open/lazy panels; Canvas, staff/SVG and OSMD app-owned accessibility
wrappers; MIDI/device status; and cache invalidation. Original authored text is
preserved. Unknown external detail belongs in an explicitly labeled technical-
detail disclosure, not an ordinary app-owned message.

Before converting their messages, replace semantic checks on English prose such
as `results-summary.js` checking `message.includes('inconsistent')` and
`library-view.js` recognizing aborts with an English regular expression. Use
stable codes or causes. These existing-module fixes are outside this foundation.

Run `node --test tests/i18n.test.js`. It covers exact catalog contracts, default
and persisted choice, storage failures/retry, document language/node preservation,
subscriptions/invalidation, missing and untrusted parameters, long labels,
plural/number/date/elapsed formatting, stable codes and bounded reports. Linkedom
checks text/attribute safety; it is not a rendered visual/accessibility audit.
Real layout in both locales, high zoom, Canvas redraw, live OSMD behavior and
physical input must be verified at the integration stage. No GUI/browser launch
is needed for these tests. The coordinator must include this file in the aggregate
test command before treating the foundation as part of the release gate.
